# Проверки этой итерации

- `npm run typecheck` — успешно.
- `npm run lint` — успешно.
- `npm run build` — успешно; экраны игры загружаются отдельными модулями.
- Выборочно проверены настройки устройства и язык, аудио, восстановление после ошибки, клиентское состояние, свои задания, каталог, игровой автомат и правила честности. Обнаруженное рассогласование задания с книгой и списка AI-проверки исправлено; соответствующие 30 тестов повторно прошли.
- Собранный сервер запускался с `NODE_ENV=production` и отдельной временной базой: документ приложения, CSP, `/healthz`, `/readyz`, гостевая сессия и отказ закрытого auth-запроса проверены.
- Команда резервного копирования создала читаемый согласованный снимок SQLite с применёнными миграциями.
- `docker compose config --quiet` — успешно.
- `git diff --check` — без ошибок.

По просьбе владельца браузерный и полный повторный прогон не выполнялись. В этой итерации не проверены живые камеры на двух устройствах, реальный AI-провайдер, Docker-образ под Linux, HTTPS на хостинге и нагрузка. Последовательность проверки перед открытием доступа игрокам есть в [DEPLOYMENT.md](DEPLOYMENT.md).

## Что изменилось для игрока

Обычная игра стала режимом по умолчанию; рейтинг выбирается отдельно. Результат показывает реванш сразу, подробный разбор раундов свёрнут. Реальные победы сопровождаются коротким огненным эффектом и разными звуками для раунда, серии и матча. Интервал между раундами уменьшен до 3,2 секунды. Подсказки открываются по нажатию. Системное уменьшение движения отключает декоративные эффекты; звук включается только по желанию игрока.

Настройки позволяют выбрать светлую неоновую, тёмную или системную тему, русский, английский или язык устройства. Русский подбор заданий не включает задания на знание английских названий предметов. Свои задания принимают кириллицу, сохраняя ограничения длины и запрет управляющих символов.
